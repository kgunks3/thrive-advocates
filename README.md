# THRIVEAdvocates website

Static site (plain HTML + CSS, no build step). Host it with GitHub Pages.

## Before publishing
- In `index.html`, replace the two `href="#"` links ("Schedule Today" and "Connect With Us") with your real links.
- Swap the images in `assets/` for your original files if you have higher-quality versions (keep the same file names).

## Publish with GitHub Pages
1. Upload everything in this folder to a public GitHub repo (keep `index.html` at the top level).
2. Repo Settings > Pages > Deploy from branch `main`, folder `/ (root)`.
3. Add your custom domain under Settings > Pages and point your DNS to GitHub.
